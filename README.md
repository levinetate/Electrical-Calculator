# Electrical Calculator

NEC 2023 field calculators for electricians: grounding and bonding, parallel feeds, generators, motors and taps, load calcs, transformers, MSB/MCC, voltage drop, EV charging, PV, conduit fill, box sizing, wire and phase colors, Ohm's law, watts/amps, and a ft-in-1/16″ construction calculator with metric/SAE conversion.

The same app ships two ways: as an **iPhone app** (Capacitor) and as an **installable web app** (PWA). Everything lives in `www/`.

Results are for reference. Verify against the adopted code, manufacturer data, and the AHJ.

## iPhone app (needs a Mac)
1. Install **Xcode** from the Mac App Store and **Node.js** (nodejs.org).
2. Clone this repo, then in the folder run:
   ```
   npm install
   npm run ios
   ```
   That copies `www/` into the iOS project and opens it in Xcode.
3. In Xcode, select the **App** target → **Signing & Capabilities** → pick your team (sign in with your Apple ID). A free Apple ID can install on your own phone for 7 days at a time; the **Apple Developer Program** ($99/yr) is needed for TestFlight and the App Store.
4. Plug in your iPhone, choose it at the top of Xcode, and press **Run** (▶).

Bundle ID is `com.levine.electricalcalculator` (in `capacitor.config.ts` and the Xcode project). Change it before the first App Store upload if you want a different one; it can't change after.

After editing anything in `www/`, run `npm run sync` (or `npm run ios`) so the iOS project gets the new files.

## Web app (any phone, free)
Upload the **`www`** folder to any https host:
- **Netlify Drop:** app.netlify.com/drop, drag the `www` folder onto the page.
- **GitHub Pages:** Settings → Pages, deploy from a branch.

Then on a phone: **iPhone** Safari → Share → **Add to Home Screen**; **Android** Chrome → ⋮ → **Install app**. Open it once with a signal; after that it works offline.

Links like `index.html#vd` open a calculator directly (`#gec`, `#bj`, `#egc`, `#rod`, `#par`, `#gen`, `#mot`, `#ld`, `#xf`, `#sb`, `#vd`, `#ev`, `#pv`, `#cf`, `#bx`, `#wc`, `#pie`, `#wa`, `#cc`).

## Updating the calculator
Edit `www/index.html`, then bump `VERSION` at the top of `www/sw.js` (e.g. `elec-calc-v16`) so installed web apps refresh, and run `npm run sync` for iOS.
